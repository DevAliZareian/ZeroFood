# ZeroFood

A **React.js-based** food ordering platform inspired by [SnapFood](https://snappfood.ir). It offers users a seamless experience to explore restaurants, place orders, and allows restaurant owners to register and sell their meals effortlessly.

![UI-hero](https://github.com/DevAliZareian/ZeroFood/blob/main/resources/UI-hero.png)

## Installation

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/DevAliZareian/ZeroFood.git

# Navigate into the project directory
cd ZeroFood

# Install dependencies
npm install

# Start the development server
npm run dev
